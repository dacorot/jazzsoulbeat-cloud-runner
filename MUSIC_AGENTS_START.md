# Jazz Soul Beat — read-only music research trigger

This file triggers the metadata-only music research workflow.

Safety rules:
- Do not download, probe, transform, remix, or otherwise modify audio.
- Do not mark any track approved or set rights_verified to yes.
- Treat Internet Archive entries only as secondary leads, never as primary rights evidence.
- Record claimed license URLs, creator/uploader metadata, source page, and any duration supplied by metadata.
- Leave composition, arrangement, performance, master, synchronization, commercial use, YouTube monetization, and streaming rights unknown until independently verified from primary sources.
- Persist research metadata only to the private Google Drive library.
- Do not upload GitHub Actions artifacts, publish to YouTube, or change any privacy setting.
